## 一、怎样打开网站

网站正在你的电脑上运行（本地预览）：

- **电脑本机**：浏览器打开 http://localhost:4321/
- **手机查看**：手机连接与电脑**同一个 Wi-Fi**，浏览器打开 http://10.179.205.96:4321/
  （若手机打不开，通常是 Windows 防火墙拦截，告诉我一声，我来处理）

如果预览关掉了，重新启动方法（无需懂代码，双击或粘贴即可）：
1. 在文件夹 `D:\Documents\qwen-agent\0p9ZxbDVxl\default\huitong-tower-website` 的地址栏输入 `cmd` 回车；
2. 输入 `npm run dev` 回车，看到 `Local http://localhost:4321/` 即启动成功。

## 二、修改网站内容（不需要改代码）

所有内容集中在一个文件里：

`src\data\site.ts`

- 招商电话、地址、邮箱：在文件顶部 `contact` 处修改（当前为占位信息，请替换为真实内容）；
- 项目概况、建筑参数、区位交通、品质认证、楼层、物业服务、业态、意向客户：按文件中的中文注释对应修改文字即可；
- 四个栏目的长篇文章：在 `src\content\pages\` 目录下的 4 个 `.md` 文件里直接改文字。

改完后网站会自动刷新（预览运行中）；重新输入 `npm run dev` 也能看到最新内容。

## 三、更换网站图片

把新图片放进 `public\images\` 目录，然后在 `src\data\site.ts` 中把对应 `/images/文件名` 改成新文件名即可。
